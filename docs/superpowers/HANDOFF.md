## 6. 미결 위험

### 6-A. arXiv 저자 쿼리 형식 — 해결됨 (커밋 `7fca264`)

**구현자도 리뷰어도 틀렸다.** 라이브 수집에서 arXiv가 HTTP 200에 0건을 반환하는 것을 확인하고
(429 없이) 실측한 결과:

| 쿼리 | totalResults |
|---|---|
| `au:"Karpathy_A"` (당시 구현) | 0 |
| `au:Karpathy_A` (따옴표 제거) | 0 |
| `au:"Karpathy_Andrej"` | 8 |
| `au:"Weng_L"` | 6 |
| `au:"Weng_Lilian"` | 23 |

따옴표는 무관했다 — 리뷰어 가설 기각. 원인은 레지스트리의 저자 문자열이 `성_이니셜` 형식이었던
것이고, 이 형식은 아예 0건이거나 일부만 매칭된다. `registry/`를 `성_이름`으로 고치고 어댑터에
근거를 주석으로 남겼다. `export.arxiv.org`는 https로 갱신했다.

**레지스트리에 arXiv 소스를 추가할 때는 `성_이름` 형식을 쓰고, 추가 직후 실제 건수를 확인할 것.**
형식이 틀려도 에러가 아니라 빈 결과라 알림에 걸리지 않는다.

### 6-E. 락파일이 npm 12에서 거부된다 (우회 중)

첫 CI가 `npm ci`에서 EUSAGE로 죽었다: `Missing: @emnapi/runtime@1.11.3 from lock file`.

`package-lock.json`이 `@img/sharp-wasm32`·`@tailwindcss/oxide-wasm32-wasi` 같은
optional wasm 패키지의 의존성으로 `@emnapi/runtime`·`core`를 참조하면서 정작 그
패키지 항목은 담고 있지 않다. **npm 11은 통과시키고 npm 12는 거부한다.**

`node-version: 24`는 러너가 최신 24.x(24.19.0)를 잡고 그 Node가 npm 12.0.2를
번들한다. 로컬은 Node 24.11.1 / npm 11.6.2 — 그래서 로컬 검증만으로는 안 잡혔다.
`npx npm@latest ci`로 정확히 재현했다.

**지금은 `.nvmrc`(24.11.1) + `node-version-file`로 CI를 고정해 우회 중이다.**
근본 해결은 npm 12로 락파일을 재생성하는 것인데, npm 12가 Node 24.15+ 를 요구해서
로컬(24.11.1)에서는 못 한다. Node를 올린 뒤 `npm install --package-lock-only`를
npm 12로 돌리고 고정을 풀 것.

## 7. 환경에서 배운 것 (다시 헤매지 말 것)

- **레포 디렉터리가 0777이면 `next build`가 실패한다.** 이 환경은 world-writable 디렉터리에
  대해 `access(2)` 쓰기 검사를 거부하는데, Next가 빌드 전에 정확히 그 검사를 한다.
  `chmod 775`로 해결했고 umask가 002라 새로 생기는 디렉터리는 문제없다. **NFS 마운트 자체는
  원인이 아니다** — 처음에 그렇게 오진했다가 사용자 지적으로 바로잡았다.
- **`.next`를 공유하는 빌드를 동시에 돌리면 서로 깨진다.** NFS라 `.nfs*` 잠금 파일이 남고
  `rm -rf .next`가 EBUSY로 실패한다. 에이전트를 병렬로 돌릴 때 빌드가 겹치지 않게 할 것.
  증상이 코드 결함처럼 보이므로 주의.
- **구현 에이전트는 한 번에 하나만.** 둘이 동시에 전체 테스트를 돌리면 서로의 미완성 상태를
  본다. 리뷰어(읽기 전용)와 구현자를 병렬로 돌리는 건 안전하다.
- `shellcheck` 없음. `gh` 인증됨. `vercel` CLI 설치됨(로그인 상태 미확인).
- `content/`는 `.gitignore`에 **없는 것이 맞다** — 워크플로가 커밋하는 데이터 저장소다.
  개발 중 생성한 것은 커밋 전에 지울 것.

## 8. 이 프로젝트의 리뷰에서 반복된 교훈

계획서에 넣은 테스트 코드가 **동작을 보여주기만 하고 회귀를 잡지 못하는** 경우가 반복됐다
(Atom summary 폴백, `toExcerpt` 정규식, `asArray` 단일 항목 경로, 드롭 가드, 태그 상한,
